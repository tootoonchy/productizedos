## Assessment Overview

The Founder DNA Assessment consists of **8 carefully designed questions** that evaluate founders across three core dimensions:

- **Motivational Core** (Questions 1-3): Identifies what fundamentally drives you as an entrepreneur
- **Action Style** (Questions 4-6): Reveals how you naturally execute and take action
- **Strategic Stance** (Questions 7-8): Determines your approach to strategy and decision-making

Each question presents **4-5 options** that map to specific dimensions. Founders select the option that best resonates with their natural approach, and their selections determine their unique Founder DNA profile.

### Assessment Characteristics

- **Duration**: 5-8 minutes
- **Total Questions**: 8
- **Question Format**: Multiple choice (4-5 options per question)
- **Scoring Method**: Dimensional tallying across three pillars
- **Result**: One of 16 comprehensive founder profiles

## Scoring Framework

### Pillar 1: Motivational Core (5 Types)

Each option in questions 1-3 maps to one of five motivational archetypes:

| Code | Type | Core Drive |
|------|------|------------|
| **PI** | Pioneer | Innovation, disruption, creating the future |
| **AR** | Architect | System design, strategic frameworks, comprehensive solutions |
| **CR** | Craftsman | Excellence, mastery, quality, technical depth |
| **CO** | Connector | Relationships, community, bringing people together |
| **AN** | Analyst | Data, optimization, evidence-based decisions |

### Pillar 2: Action Style (3 Types)

Each option in questions 4-6 maps to one of three action modes:

| Code | Type | Execution Approach |
|------|------|-------------------|
| **CA** | Catalyst | Rapid experimentation, quick iteration, speed |
| **OR** | Orchestrator | Coordination, systems, delegation, scaling |
| **MA** | Maker | Hands-on building, direct implementation, craftsmanship |

### Pillar 3: Strategic Stance (2 Types)

Each option in questions 7-8 maps to one of two strategic approaches:

| Code | Type | Strategic Philosophy |
|------|------|---------------------|
| **EF** | Effectual | Means-driven, flexible, emergent strategy |
| **CS** | Causal | Goal-driven, planned, predictive strategy |

## Scoring Logic

### Step 1: Tally Responses by Dimension

After the user completes all 8 questions, count their selections for each dimension:

**Motivational Core Tallies:**
- Pioneer (PI): Count of questions 1-3 answered with Pioneer options
- Architect (AR): Count of questions 1-3 answered with Architect options
- Craftsman (CR): Count of questions 1-3 answered with Craftsman options
- Connector (CO): Count of questions 1-3 answered with Connector options
- Analyst (AN): Count of questions 1-3 answered with Analyst options

**Action Style Tallies:**
- Catalyst (CA): Count of questions 4-6 answered with Catalyst options
- Orchestrator (OR): Count of questions 4-6 answered with Orchestrator options
- Maker (MA): Count of questions 4-6 answered with Maker options

**Strategic Stance Tallies:**
- Effectual (EF): Count of questions 7-8 answered with Effectual options
- Causal (CS): Count of questions 7-8 answered with Causal options

### Step 2: Determine Dominant Type in Each Pillar

For each pillar, select the dimension with the highest count:

**Motivational Core**: Select the type with the highest count among PI, AR, CR, CO, AN
- If tied, use the first question (Q1) as the tiebreaker

**Action Style**: Select the type with the highest count among CA, OR, MA
- If tied, use the fourth question (Q4) as the tiebreaker

**Strategic Stance**: Select the type with the highest count among EF, CS
- If tied (1-1), default to Effectual (EF) as it's more common in early-stage founders

### Step 3: Combine to Form Profile ID

Combine the three dominant types to create the profile identifier:

**Format**: `{motivational-core}-{action-style}-{strategic-stance}`

**Example**:
- Motivational Core: Pioneer (PI)
- Action Style: Catalyst (CA)
- Strategic Stance: Effectual (EF)
- **Profile ID**: `pioneer-catalyst-effectual`
- **Profile Name**: The Visionary Catalyst

## Implementation Guidelines

### Question Display

**Format**: Present questions one at a time with clear progress indication

**Progress Bar**: Show completion percentage (e.g., "Question 3 of 8 - 37% Complete")

**Section Headers**: Clearly mark transitions between sections:
- "Part 1: What Drives You" (Questions 1-3)
- "Part 2: How You Execute" (Questions 4-6)
- "Part 3: Your Strategic Approach" (Questions 7-8)

**Option Display**: 
- Use radio buttons for single selection
- Display full option text (not abbreviated)
- Ensure options are visually distinct and easy to select on mobile

### User Experience Considerations

**Navigation**:
- Allow users to go back and change previous answers
- Save progress automatically (if logged in)
- Provide a "Review Answers" screen before final submission

**Validation**:
- Require an answer for each question before proceeding
- Provide clear error messages if user tries to skip

**Time Estimate**:
- Display "5-8 minutes" estimate on the start screen
- Show time remaining or questions remaining

### Data Collection

**Store the following for each assessment**:
- User ID (if registered)
- Timestamp of completion
- Individual question responses (Q1-Q8 with selected options)
- Calculated dimension tallies
- Final profile ID
- Final profile name

**Privacy Considerations**:
- Clearly communicate data usage in privacy policy
- Allow users to delete their assessment data
- Do not share individual responses without explicit consent

### Scoring Implementation

**Pseudo-code for scoring logic**:

```javascript
function calculateFounderDNA(answers) {
  // Initialize tallies
  const tallies = {
    motivational: { PI: 0, AR: 0, CR: 0, CO: 0, AN: 0 },
    action: { CA: 0, OR: 0, MA: 0 },
    strategic: { EF: 0, CS: 0 }
  };
  
  // Tally responses
  // Q1-Q3: Motivational Core
  tallies.motivational[answers.q1]++;
  tallies.motivational[answers.q2]++;
  tallies.motivational[answers.q3]++;
  
  // Q4-Q6: Action Style
  tallies.action[answers.q4]++;
  tallies.action[answers.q5]++;
  tallies.action[answers.q6]++;
  
  // Q7-Q8: Strategic Stance
  tallies.strategic[answers.q7]++;
  tallies.strategic[answers.q8]++;
  
  // Determine dominant types
  const motivationalCore = findMax(tallies.motivational, answers.q1);
  const actionStyle = findMax(tallies.action, answers.q4);
  const strategicStance = findMax(tallies.strategic, 'EF'); // Default to EF on tie
  
  // Generate profile ID
  const profileId = `${motivationalCore}-${actionStyle}-${strategicStance}`.toLowerCase();
  
  return {
    profileId,
    tallies,
    dominantTypes: { motivationalCore, actionStyle, strategicStance }
  };
}

function findMax(tally, tiebreaker) {
  const max = Math.max(...Object.values(tally));
  const winners = Object.keys(tally).filter(k => tally[k] === max);
  return winners.length === 1 ? winners[0] : tiebreaker;
}
```

## Question Design Principles

### Why These Questions Work

**1. Forced Choice Format**
Each question requires selecting one option, forcing founders to prioritize and reveal their dominant tendencies rather than rating all options highly.

**2. Behavioral Focus**
Questions ask about actual behaviors and preferences ("How do you prefer...") rather than abstract self-descriptions ("Are you..."), leading to more accurate self-assessment.

**3. Entrepreneurial Context**
All questions are framed specifically in entrepreneurial contexts, ensuring relevance and helping founders think about their business-building approach.

**4. Balanced Options**
Each option is written to be equally appealing to its target dimension, avoiding obviously "better" or "worse" choices that would bias responses.

**5. Clear Differentiation**
Options within each question are distinct enough that founders can identify which resonates most, while still being realistic (not caricatures).

### Question Validation

These questions have been designed based on:
- **Entrepreneurial Orientation (EO) Theory**: Questions 1-3 draw from EO dimensions of innovativeness, proactiveness, and risk-taking
- **Effectuation Theory**: Questions 7-8 directly map to effectual vs. causal logic as defined by Sarasvathy
- **Kolbe A Index**: Questions 4-6 are inspired by Kolbe's action modes (Fact Finder, Follow Thru, Quick Start, Implementor)
- **Enneagram Theory**: Questions 1-3 incorporate motivation-based typing from Enneagram, adapted for entrepreneurial contexts
